# Система автопостинга статей с Giga Chat API

## Описание

Система автоматической генерации статей с использованием шаблонов промптов и Giga Chat API. Позволяет создавать шаблоны промптов для каждого элемента статьи (заголовок, описание, контент, изображение) и настраивать автоматическую генерацию по расписанию.

## Основные компоненты

### 1. Модели

#### `PromptTemplate` - Шаблон промпта
Содержит промпты для генерации каждого элемента статьи:
- `title_prompt` - промпт для заголовка
- `description_prompt` - промпт для описания (Telegram)
- `content_prompt` - промпт для основного контента
- `image_prompt` - промпт для генерации изображения (GigaChat-Pro)

#### `AISchedule` - Расписание генерации
Настройки автоматической генерации:
- Выбор шаблона промпта
- Частота генерации (hourly, daily, weekly, monthly, custom)
- Количество статей за раз
- Категория, теги, ключевые слова
- Модели GigaChat (обычная для текста, PRO для изображений)

#### `AIGeneratedArticle` - История генерации
Сохраняет информацию о каждой сгенерированной статье:
- Использованные промпты
- Ответы AI
- Контекст генерации
- Время генерации

### 2. Сервисы

#### `ArticleGeneratorService`
Основной сервис для генерации статей:
- Генерация заголовка через GigaChat
- Генерация контента через GigaChat
- Генерация описания для Telegram
- Генерация изображений через GigaChat-Pro (опционально)
- Сохранение истории генерации

### 3. Задачи Django-Q

#### `run_schedule_task(schedule_id)`
Задача для автоматической генерации по расписанию. Вызывается Django-Q по CRON расписанию.

#### `setup_schedules()`
Настройка расписаний в Django-Q при создании/обновлении AISchedule.

## Использование

### 1. Создание шаблона промпта

1. Перейдите в админ-панель → **Шаблоны промптов**
2. Нажмите **Добавить шаблон промпта**
3. Заполните поля:
   - **Название шаблона** - например, "Статьи о красоте"
   - **Промпт для заголовка** - например:
     ```
     Создай привлекательный заголовок для статьи о {topic} в категории {category}. 
     Заголовок должен быть интересным и содержать ключевые слова: {keywords}
     ```
   - **Промпт для описания** - например:
     ```
     Создай краткое описание статьи "{title}" для публикации в Telegram. 
     Описание должно быть до 200 символов и привлекать внимание.
     ```
   - **Промпт для основного контента** - например:
     ```
     Напиши уникальную статью на тему "{topic}" для категории {category}. 
     Используй ключевые слова: {keywords}. 
     Тон: {tone}. 
     Статья должна быть 500-1500 слов, с HTML разметкой (h2, h3, ul, ol, blockquote).
     ```
   - **Промпт для изображения** (опционально) - например:
     ```
     Создай изображение для статьи "{title}" на тему {topic}. 
     Изображение должно быть стильным и привлекательным.
     ```
4. Укажите категорию и теги по умолчанию (если нужно)
5. Сохраните

### 2. Создание расписания

1. Перейдите в админ-панель → **Расписания генерации**
2. Нажмите **Добавить расписание генерации**
3. Заполните поля:
   - **Название расписания** - например, "Ежедневные статьи о красоте"
   - **Шаблон промпта** - выберите созданный шаблон
   - **Частота генерации** - выберите из списка или "Произвольное" для CRON
   - **CRON выражение** - если выбрано "Произвольное", укажите CRON (например: `0 9 * * *` для 9:00 каждый день)
   - **Статей за раз** - количество статей для генерации за один запуск
   - **Категория** - категория для статей (если не указана, используется из шаблона)
   - **Теги** - теги через запятую
   - **Ключевые слова** - ключевые слова для генерации контента
   - **Дополнительные данные** (JSON) - например:
     ```json
     {
       "topic": "уход за кожей",
       "tone": "дружелюбный и экспертный"
     }
     ```
   - **Модель для текста** - обычно "GigaChat"
   - **Модель для изображений** - обычно "GigaChat-Pro"
   - **Генерировать изображения** - включить генерацию изображений через GigaChat-Pro
4. Сохраните

### 3. Запуск генерации

#### Автоматический запуск
Расписание автоматически настроится в Django-Q при сохранении. Убедитесь, что запущен воркер:
```bash
python manage.py qcluster
```

#### Ручной запуск
В админ-панели в списке расписаний:
1. Выберите нужное расписание
2. В действиях выберите **"Запустить генерацию сейчас"**
3. Нажмите **Выполнить**

### 4. Просмотр истории

Перейдите в админ-панель → **Сгенерированные статьи** для просмотра истории генерации:
- Сгенерированные данные
- Использованные промпты
- Ответы AI
- Время генерации

## Переменные в промптах

В промптах можно использовать следующие переменные для подстановки:

- `{topic}` - тема статьи (из context_data или keywords)
- `{category}` - название категории
- `{keywords}` - ключевые слова
- `{tone}` - тон статьи (из context_data)
- `{title}` - заголовок статьи (доступен в промптах для описания и контента)
- `{content}` - контент статьи (доступен в промпте для описания)

Также можно использовать любые переменные из `context_data` расписания.

## Примеры промптов

### Промпт для заголовка
```
Создай привлекательный заголовок для статьи о {topic} в категории {category}. 
Заголовок должен быть интересным, содержать эмодзи и привлекать внимание читателей.
```

### Промпт для контента
```
Напиши уникальную статью на тему "{topic}" для категории {category}. 

Требования:
- Объем: 800-1200 слов
- Тон: {tone}
- Используй ключевые слова: {keywords}
- Структура: введение, основная часть с подзаголовками, заключение
- HTML разметка: h2, h3, ul, ol, blockquote
- Добавь практические советы и примеры
- Избегай копирования, пиши уникальный контент

Начни с заголовка: {title}
```

### Промпт для описания
```
Создай краткое описание статьи "{title}" для публикации в Telegram. 
Описание должно быть до 200 символов, привлекательным и содержать призыв к действию.
```

### Промпт для изображения
```
Создай стильное изображение для статьи "{title}" на тему {topic}. 
Изображение должно быть привлекательным, профессиональным и соответствовать теме статьи.
```

## Настройка GigaChat

Убедитесь, что в настройках AI-ассистента (`AssistantSettings`) указаны:
- **GigaChat Authorization Key** - ключ авторизации из личного кабинета Studio
- **GigaChat Scope** - обычно `GIGACHAT_API_PERS` для физических лиц
- **AI модель** - модель по умолчанию (обычно "GigaChat")

## Примечания

1. **Генерация изображений**: Для генерации изображений через GigaChat-Pro требуется модель с поддержкой генерации изображений. Убедитесь, что ваша подписка поддерживает эту функцию.

2. **CRON выражения**: Формат CRON: `минута час день месяц день_недели`
   - Примеры:
     - `0 9 * * *` - каждый день в 9:00
     - `0 */2 * * *` - каждые 2 часа
     - `0 9 * * 1` - каждый понедельник в 9:00

3. **Производительность**: Генерация одной статьи может занять 30-60 секунд в зависимости от объема контента и загрузки API.

4. **Логирование**: Все операции логируются. Проверяйте логи для отладки:
   ```bash
   tail -f logs/django.log
   ```

## Устранение неполадок

### Статьи не генерируются
1. Проверьте, что расписание активно (`is_active=True`)
2. Убедитесь, что запущен воркер Django-Q: `python manage.py qcluster`
3. Проверьте логи на наличие ошибок
4. Убедитесь, что указаны правильные настройки GigaChat

### Ошибки генерации
1. Проверьте, что все обязательные поля заполнены (категория, промпты)
2. Убедитесь, что модель GigaChat доступна и правильно настроена
3. Проверьте логи для детальной информации об ошибке

### Расписание не работает
1. Проверьте, что расписание создано в Django-Q (админ-панель → Django Q → Schedules)
2. Убедитесь, что CRON выражение корректно
3. Проверьте, что воркер Django-Q запущен
