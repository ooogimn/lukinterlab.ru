# Инструкция по настройке автопостинга статей

## Описание системы

Система автоматической генерации и публикации статей с:
- Поиском актуальных новостей из различных источников
- Парсингом контента (100-200 слов)
- Генерацией через GigaChat (заголовок, текст 800-1300 слов, изображение, FAQ)
- SEO оптимизацией (метатеги, structured data)
- Отправкой в поисковые системы (Google, Yandex, Bing)
- Расписанием: с 8:00 каждый день, по 1 статье каждые 20 минут (10 статей)
- Умной ротацией категорий (популярные в 2 раза чаще)

## Установка зависимостей

```bash
pip install feedparser beautifulsoup4 lxml
```

Или обновите requirements.txt (уже добавлено):
```bash
pip install -r requirements.txt
```

## Настройка базы данных

1. Создайте миграции:
```bash
python manage.py makemigrations Assistant Blog
```

2. Примените миграции:
```bash
python manage.py migrate
```

## Создание шаблона промпта

Выполните команду для создания шаблона промпта по умолчанию:

```bash
python manage.py create_default_prompt_template
```

Или создайте вручную в админ-панели:
- Перейдите в **Assistant → Шаблоны промптов**
- Создайте новый шаблон "Передовая ИИ/IT компания"
- Заполните промпты (см. примеры в команде `create_default_prompt_template.py`)

## Настройка расписания

Выполните команду для настройки расписания автопостинга:

```bash
python manage.py setup_autoposting_schedule
```

Эта команда:
- Создаст расписание `AISchedule` для автопостинга
- Создаст 10 расписаний Django-Q (8:00, 8:20, 8:40, 9:00, 9:20, 9:40, 10:00, 10:20, 10:40, 11:00)

## Запуск воркера Django-Q

Для работы автопостинга необходимо запустить воркер Django-Q:

```bash
python manage.py qcluster
```

## Проверка работы

1. Проверьте расписания в админ-панели:
   - **Django Q → Schedules** - должно быть 10 расписаний
   - **Assistant → Расписания генерации** - должно быть расписание "Автопостинг статей"

2. Проверьте логи:
```bash
tail -f logs/django.log
```

3. Проверьте сгенерированные статьи:
   - **Blog → Статьи** - должны появляться новые статьи
   - **Assistant → Сгенерированные статьи** - история генерации

## Настройка поисковых систем (опционально)

Для отправки через API (вместо ping) добавьте в `settings.py`:

```python
# Google Search Console API (опционально)
GOOGLE_SEARCH_CONSOLE_API_KEY = 'your_key'

# Yandex Webmaster API (опционально)
YANDEX_WEBMASTER_TOKEN = 'your_token'

# Bing Webmaster Tools API (опционально)
BING_WEBMASTER_API_KEY = 'your_key'
```

## Настройка источников новостей

Источники новостей настраиваются в `Assistant/news_parser.py` в классе `NewsParserService`.

По умолчанию используются:
- Google News RSS
- Yandex News RSS
- RIA Novosti RSS
- TASS RSS

## Мониторинг и статистика

1. **Статистика источников новостей:**
   - **Assistant → Источники новостей** - рейтинг источников по просмотрам

2. **Статистика категорий:**
   - **Assistant → Статистика категорий** - приоритеты категорий для ротации

3. **Использование токенов:**
   - **Assistant → Использование токенов** - мониторинг использования GigaChat API

## Процесс генерации статьи

1. **Выбор категории** - умная ротация (популярные в 2 раза чаще)
2. **Поиск новостей** - через все источники, выбор оптимального
3. **Парсинг контента** - 100-200 слов из источника
4. **Генерация заголовка** - через GigaChat
5. **Генерация контента** - 800-1300 слов через GigaChat
6. **Генерация FAQ** - 5-7 вопросов и ответов
7. **Генерация изображения** - через GigaChat-Pro или из новости
8. **Генерация тегов** - для перелинковки статей
9. **SEO оптимизация** - метатеги и structured data
10. **Отправка в поисковые системы** - Google, Yandex, Bing

## Устранение неполадок

### Статьи не генерируются

1. Проверьте, что расписание активно
2. Убедитесь, что запущен воркер: `python manage.py qcluster`
3. Проверьте логи на наличие ошибок
4. Убедитесь, что указаны правильные настройки GigaChat

### Ошибки парсинга новостей

1. Проверьте доступность источников новостей
2. Проверьте интернет-соединение
3. Проверьте логи на детали ошибок

### Ошибки генерации

1. Проверьте лимиты токенов GigaChat
2. Убедитесь, что все промпты заполнены
3. Проверьте логи для детальной информации

## Дополнительные настройки

### Изменение расписания

Отредактируйте расписание в админ-панели:
- **Assistant → Расписания генерации**
- Измените `cron_expression` для другого времени

### Изменение промптов

Отредактируйте шаблон промпта в админ-панели:
- **Assistant → Шаблоны промптов**
- Измените промпты для заголовка, контента, FAQ, изображения

### Отключение генерации изображений

В расписании установите `use_image_generation = False`

## Поддержка

При возникновении проблем проверьте:
1. Логи Django: `logs/django.log`
2. Логи Django-Q: в админ-панели **Django Q → Failed Tasks**
3. Настройки GigaChat: **Assistant → Настройки ассистента**
