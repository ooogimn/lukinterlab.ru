# Быстрый старт автопостинга статей

## Шаг 1: Установка зависимостей

```bash
pip install feedparser beautifulsoup4 lxml
```

Или обновите requirements.txt (уже добавлено):
```bash
pip install -r requirements.txt
```

## Шаг 2: Миграции базы данных

```bash
python manage.py makemigrations Assistant Blog
python manage.py migrate
```

## Шаг 3: Создание шаблона промпта

```bash
python manage.py create_default_prompt_template
```

Эта команда создаст шаблон "Передовая ИИ/IT компания" с промптами для:
- Заголовка
- Контента (800-1300 слов)
- FAQ блока
- Изображения

## Шаг 4: Настройка расписания

```bash
python manage.py setup_autoposting_schedule
```

Эта команда:
- Создаст расписание AISchedule
- Создаст 10 расписаний Django-Q (8:00, 8:20, 8:40, 9:00, 9:20, 9:40, 10:00, 10:20, 10:40, 11:00)

## Шаг 5: Запуск воркера Django-Q

```bash
python manage.py qcluster
```

## Проверка работы

1. Проверьте расписания в админ-панели:
   - **Django Q → Schedules** - должно быть 10 расписаний
   - **Assistant → Расписания генерации** - должно быть расписание "Автопостинг статей"

2. Проверьте логи:
```bash
tail -f logs/django.log
```

3. Проверьте сгенерированные статьи:
   - **Blog → Статьи** - должны появляться новые статьи
   - **Assistant → Сгенерированные статьи** - история генерации

## Что происходит при генерации статьи

1. **Выбор категории** - умная ротация (популярные в 2 раза чаще)
2. **Поиск новостей** - через все источники (Google News, Yandex News, RIA, TASS)
3. **Парсинг контента** - 100-200 слов из источника
4. **Генерация заголовка** - через GigaChat
5. **Генерация контента** - 800-1300 слов через GigaChat
6. **Генерация FAQ** - 5-7 вопросов и ответов (JSON-LD + HTML)
7. **Генерация изображения** - через GigaChat-Pro или из новости
8. **Генерация тегов** - для перелинковки статей
9. **SEO оптимизация** - метатеги и structured data
10. **Отправка в поисковые системы** - Google, Yandex, Bing

## Настройка

### Изменение расписания

Отредактируйте в админ-панели:
- **Assistant → Расписания генерации**
- Измените `cron_expression` или время запуска

### Изменение промптов

Отредактируйте в админ-панели:
- **Assistant → Шаблоны промптов**
- Измените промпты для заголовка, контента, FAQ, изображения

### Мониторинг

- **Assistant → Источники новостей** - рейтинг источников
- **Assistant → Статистика категорий** - приоритеты категорий
- **Assistant → Использование токенов** - мониторинг GigaChat API

## Устранение неполадок

### Статьи не генерируются

1. Проверьте, что расписание активно
2. Убедитесь, что запущен воркер: `python manage.py qcluster`
3. Проверьте логи на наличие ошибок
4. Убедитесь, что указаны правильные настройки GigaChat в **Assistant → Настройки ассистента**

### Ошибки парсинга новостей

1. Проверьте доступность источников новостей
2. Проверьте интернет-соединение
3. Проверьте логи для детальной информации

### Ошибки генерации

1. Проверьте лимиты токенов GigaChat
2. Убедитесь, что все промпты заполнены
3. Проверьте логи для детальной информации
