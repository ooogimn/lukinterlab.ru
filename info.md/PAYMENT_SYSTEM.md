# Система оплаты заказов LukInterLab

## 🎯 Обзор

Полностью интегрированная система оплаты заказов с использованием YooKassa (ранее ЮMoney). Позволяет клиентам оплачивать услуги онлайн с автоматическим обновлением статуса заказов.

## ✨ Возможности

### Для клиентов
- ✅ Добавление услуг в корзину
- ✅ Оформление заказа с контактными данными
- ✅ Заполнение опросного листа проекта
- ✅ Загрузка файлов и документов
- ✅ Безопасная оплата через YooKassa
- ✅ Получение уведомлений об оплате

### Для администраторов
- ✅ Просмотр всех заказов в админ-панели
- ✅ Фильтрация по статусу и дате
- ✅ Автоматические уведомления об оплате
- ✅ Telegram уведомления
- ✅ Email уведомления
- ✅ Экспорт данных заказов

## 💳 Процесс оплаты

### 1. Добавление в корзину
- Клиент выбирает услуги на главной странице
- Нажимает "Добавить в корзину"
- AJAX запрос добавляет товар в корзину

### 2. Оформление заказа
- Переход в корзину
- Заполнение контактных данных
- Создание заказа в базе данных

### 3. Опросный лист
- Заполнение деталей проекта
- Загрузка файлов
- Уточнение требований

### 4. Оплата
- Переход на страницу оплаты
- Создание платежа в YooKassa
- Перенаправление на страницу оплаты YooKassa
- Ввод данных карты
- Возврат на сайт после оплаты

### 5. Обработка результата
- Webhook получает уведомление от YooKassa
- Статус заказа обновляется автоматически
- Отправляются уведомления администратору

## 🔧 Технические детали

### Создание платежа

```python
from yookassa import Payment

payment = Payment.create({
    "amount": {
        "value": str(order.total_price),
        "currency": "RUB"
    },
    "confirmation": {
        "type": "redirect",
        "return_url": return_url
    },
    "capture": True,
    "description": f"Оплата заказа №{order.order_number}",
    "metadata": {
        "order_id": str(order.id),
        "order_number": order.order_number
    }
}, shop_id, secret_key)
```

### Обработка webhook

```python
@csrf_exempt
def yookassa_webhook(request):
    data = json.loads(request.body)
    
    if data['object']['type'] == 'payment':
        payment_data = data['object']
        order = Order.objects.get(payment_id=payment_data['id'])
        
        if payment_data['status'] == 'succeeded':
            order.payment_status = 'paid'
            order.status = 'confirmed'
            order.save()
            
            # Отправка уведомлений
            NotificationService.send_payment_notification(order)
```

## 🚨 Устранение неполадок

### Частые проблемы

1. **Заказ не создается**
   - Проверьте миграции
   - Проверьте права доступа к базе данных

2. **Оплата не проходит**
   - Проверьте настройки YooKassa
   - Убедитесь в правильности суммы
   - Проверьте тестовые карты

3. **Webhook не работает**
   - Проверьте доступность URL
   - Проверьте логи сервера
   - Убедитесь в правильности настроек
