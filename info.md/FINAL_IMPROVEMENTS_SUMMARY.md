### 1. **Правильный endpoint для генерации изображений** 🖼️

**Текущая проблема:**
- Используется предположительный endpoint `/api/v1/images/generations`
- Нужно проверить актуальную документацию

**Решение:**
1. Проверить документацию GigaChat по генерации изображений
2. Возможно, использовать chat completions с специальными параметрами
3. Добавить fallback на внешние сервисы генерации изображений

**Приоритет:** ВЫСОКИЙ

---

### 2. **Потоковая генерация для длинных статей** ⚡

**Преимущества:**
- Меньше задержка при генерации
- Лучший UX (видно прогресс)
- Экономия времени

**Реализация:**
```python
# Включить stream: True для длинных промптов
if len(prompt) > 1000:  # Для длинных промптов
    use_streaming = True
```

**Приоритет:** СРЕДНИЙ

### 8. **Подсчет токенов перед отправкой** 🔢

**Преимущества:**
- Предупреждение о превышении лимитов
- Оптимизация промптов
- Контроль расходов

**Реализация:**
```python
def count_tokens_approx(text: str) -> int:
    """Приблизительный подсчет токенов"""
    # Для русского текста: ~4 символа = 1 токен
    return len(text) // 4
```

**Приоритет:** СРЕДНИЙ
