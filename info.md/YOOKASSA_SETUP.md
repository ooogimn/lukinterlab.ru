# Настройка YooKassa для оплаты заказов

## 📋 Обзор

YooKassa (ранее ЮMoney) — это российская платежная система, которая позволяет принимать оплату за заказы на сайте. Данная инструкция поможет настроить интеграцию с YooKassa для системы заказов LukInterLab.

## 🚀 Быстрый старт

### 1. Регистрация в YooKassa

1. **Перейдите на сайт YooKassa**: https://yookassa.ru/
2. **Нажмите "Подключиться"** в правом верхнем углу
3. **Выберите тип подключения**: "Для бизнеса"
4. **Заполните форму регистрации**:
   - ИНН организации или ИП
   - Название организации
   - Контактные данные
   - Банковские реквизиты

### 2. Подтверждение документов

После регистрации необходимо предоставить документы:
- Свидетельство о регистрации ИП/ООО
- Свидетельство о постановке на учет в налоговой
- Паспортные данные руководителя
- Банковские реквизиты

### 3. Получение Shop ID и Secret Key

После одобрения заявки:

1. **Войдите в личный кабинет** YooKassa
2. **Перейдите в раздел "Настройки"** → "API"
3. **Скопируйте Shop ID** (идентификатор магазина)
4. **Создайте Secret Key**:
   - Нажмите "Создать ключ"
   - Выберите права доступа (для тестирования — полные права)
   - Скопируйте Secret Key

## ⚙️ Настройка проекта

### 1. Обновление переменных окружения

Добавьте в файл `.env`:

```env
# YooKassa Settings
YOOKASSA_SHOP_ID=123456
YOOKASSA_SECRET_KEY=test_1234567890abcdef
```

### 2. Настройка webhook (для продакшена)

Для автоматического обновления статуса заказов настройте webhook:

1. **В личном кабинете YooKassa** перейдите в "Настройки" → "Уведомления"
2. **Добавьте URL webhook**: `https://your-domain.com/webhook/yookassa/`
3. **Выберите события**:
   - `payment.succeeded` — успешная оплата
   - `payment.canceled` — отмена платежа

### 3. Тестирование

Для тестирования используйте тестовые карты YooKassa:

- **Успешная оплата**: `1111 1111 1111 1026` (срок действия: 12/25, CVV: 123)
- **Недостаточно средств**: `1111 1111 1111 1047` (срок действия: 12/25, CVV: 123)
- **Отклонена банком**: `1111 1111 1111 1051` (срок действия: 12/25, CVV: 123)

## 🔧 Техническая реализация

### Структура файлов

```
home/
├── views.py              # Views для оплаты
├── models.py             # Модель Order с payment_id
├── services.py           # Уведомления об оплате
└── urls.py               # URL-ы для оплаты

templates/home/checkout/
├── pay.html              # Страница оплаты
└── payment_success.html  # Страница успешной оплаты
```

### Основные функции

1. **pay_order** — создание платежа и перенаправление на YooKassa
2. **yookassa_webhook** — обработка уведомлений от YooKassa
3. **payment_success** — страница успешной оплаты

### Процесс оплаты

1. Пользователь оформляет заказ
2. Переходит на страницу оплаты
3. Нажимает "Оплатить"
4. Перенаправляется на страницу YooKassa
5. Вводит данные карты
6. После оплаты возвращается на сайт
7. Webhook обновляет статус заказа

## 🔒 Безопасность

### Рекомендации

1. **Никогда не храните Secret Key в коде**
2. **Используйте HTTPS** для всех запросов
3. **Проверяйте подпись webhook** (в продакшене)
4. **Логируйте все операции** с платежами
5. **Регулярно обновляйте зависимости**

### Проверка webhook

В продакшене рекомендуется проверять подпись webhook:

```python
import hmac
import hashlib

def verify_webhook_signature(request_body, signature, secret_key):
    expected_signature = hmac.new(
        secret_key.encode(),
        request_body,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(signature, expected_signature)
```

## 🚨 Устранение неполадок

### Частые проблемы

1. **"Shop ID не найден"**
   - Проверьте правильность Shop ID
   - Убедитесь, что аккаунт подтвержден

2. **"Неверный Secret Key"**
   - Проверьте правильность ключа
   - Убедитесь, что ключ активен

3. **Webhook не работает**
   - Проверьте доступность URL
   - Убедитесь, что URL доступен из интернета
   - Проверьте логи сервера

4. **Платеж не проходит**
   - Проверьте тестовые карты
   - Убедитесь, что сумма корректна
   - Проверьте валюту (должна быть RUB)

### Логирование

Для отладки включите логирование в `settings.py`:

```python
LOGGING = {
    'version': 1,
    'disable_existing_loggers': False,
    'handlers': {
        'file': {
            'level': 'DEBUG',
            'class': 'logging.FileHandler',
            'filename': 'yookassa.log',
        },
    },
    'loggers': {
        'yookassa': {
            'handlers': ['file'],
            'level': 'DEBUG',
            'propagate': True,
        },
    },
}
```
