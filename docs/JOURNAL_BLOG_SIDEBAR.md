# Журнал: сайдбар категорий блога (UI / поведение)

## 2026-04-08 — зафиксированное рабочее решение (rail-кнопки)

- Раскрытие названия категории: слой **`position: fixed`** + невидимый **spacer** в потоке, чтобы не было горизонтальной прокрутки у `nav`.
- **Критично:** при раскрытии **не** задавать кнопке inline **`width` в px** (оставалась бы 48px) — иначе **`max-width` не расширяет** блок и текст не виден при **`overflow-hidden`** из Tailwind.
- Свёрнуто: `width / min-width / max-width: 3rem`. Раскрыто: `width: auto !important`, `overflow: visible !important`.
- Вертикальная прокрутка списка: обёртка **`direction: rtl`** у `nav`, контент **`direction: ltr`** — полоса прокрутки слева от кнопок.
- `mouseleave` с небольшой задержкой (~120 ms), чтобы не схлопывало при переходе в `fixed`.

## 2026-04-08 — родительская категория и аккордеон

- При **раскрытии потомков** (клик по «галочке») кнопка **родителя** тоже переходит в раскрытый вид и **остаётся** такой, пока ветка не свёрнута той же «галочкой».
- **Клик по кнопке родителя** по-прежнему **фильтрует** статьи; раскрытие при открытых потомках **не схлопывается** от ухода курсора / потери фокуса.
- Остальные кнопки (листья, свёрнутые родители): поведение как раньше (наведение / фокус).

**Починка «галочка открывает ветку, но rail не раскрывается»:** строка с аккордеоном и кнопкой категории — класс **`blog-cat-row`**; поиск кнопки через `closest('.blog-cat-row')` (не `closest('.flex')`). После клика по аккордеону вызов **`floatRail(rail, { pin: true })`** в **`requestAnimationFrame`**. `unfloatRailForce` сначала снимает **`data-rail-pinned`**, затем слой.
