=== Git и деплой на сервер ===
Секреты в коде не хранятся — только в .env на машине (файл .env не в git). Репозиторий на GitHub лучше держать приватным до полной ротации ключей, если они уже светились в истории.

В проекте уже есть .gitignore и ветка main (git init выполнен один раз).
Локально, в каталоге lukinterlab.ru:
  git add -A
  git status
  git commit -m "Описание изменений"
  Если remote ещё не настроен — на GitHub/GitLab создать пустой приватный репозиторий, затем:
  git remote add origin <URL>
  git push -u origin main
  При ошибке "index.lock" — закрыть другие окна с этим репозиторием и удалить файл .git/index.lock, повторить git add.

На сервере (первый раз — клон в каталог сайта или отдельно + symlink):
  cd ~/domains/lukinterlab.ru
  git clone <URL> .          # если каталог пустой, или git init + remote add + pull
  # дальше при каждом обновлении:
  git pull origin main
  # Убедиться, что на сервере есть .env (или переменные в панели) с DJANGO_SECRET_KEY, DJANGO_DEBUG=False, ключами API.
  source <путь-к-venv>/bin/activate   # или свой способ активации venv на хостинге
  pip install -r requirements.txt    # при изменении зависимостей
  python manage.py migrate
  python manage.py collectstatic --noinput
  Перезапуск приложения (панель хостинга / touch tmp/restart.txt / gunicorn и т.д.)

Не коммитится (.gitignore): db.sqlite3, media/, static/ (собранная), .venv, логи.

Автопостинг статей блога на стену сообщества VK (уже в коде: Blog/vk_utils.send_to_vk)
Это ОТДЕЛЬНЫЙ ключ от VK ID (сервисный/защищённый ключ приложения для wall.post не подходят).

1) Откройте сообщество как администратор → Управление → Настройки → Работа с API.
2) Создать ключ → отметить права «Стена», «Фотографии» → скопировать токен.
3) ID группы в settings: VK_GROUP_ID (сейчас 231035215; при другой группе замените или задайте VK_GROUP_ID в окружении).
4) На хостинге: в .env переменная VK_ACCESS_TOKEN=<токен> и перезапуск приложения (gunicorn/uwsgi/panel).
5) SITE_URL должен быть https://lukinterlab.ru (уже задан) — в пост идёт ссылка «Читать далее».
6) Пост уходит при первой публикации статьи (status=published), если vk_posted_at пусто. VK_AUTO_POST=True.

Проверка: опубликовать тестовую статью в админке → запись на стене группы; ошибки — в логах Django (VK wall.post).
