План комплексной SEO оптимизации для lukinterlab.ru
Анализ текущего состояния
Что уже есть:
Базовая SEO инфраструктура (SEOModel, SEOUtils, SEOService)
Sitemap.xml и robots.txt настроены
Базовые мета-теги в base.html
Structured data для главной страницы и работ
WebP версии изображений через ImageKit
Команда optimize_seo.py для автогенерации
Критические проблемы:
Модель Post не имеет SEO полей - нет meta_title, meta_description, og_image
Нет structured data (JSON-LD) для статей блога
Нет автогенерации SEO мета-тегов при создании/обновлении статей
Нет breadcrumbs structured data для статей
Неполная оптимизация изображений - нет alt текстов везде, нет lazy loading
Нет внутренней перелинковки между статьями
Нет микроразметки FAQ, HowTo для статей
Нет автогенерации canonical URL для статей
План реализации
Этап 1: Расширение модели Post (КРИТИЧНО)
Файл: Blog/models.py

Добавить SEO поля в модель Post:

meta_title (CharField, max_length=60) - для переопределения title
meta_description (CharField, max_length=160) - для переопределения description  
meta_keywords (TextField, blank=True) - ключевые слова
og_image (ImageField, blank=True) - отдельное изображение для соцсетей
focus_keyword (CharField, max_length=50, blank=True) - главное ключевое слово
seo_score (IntegerField, default=0) - кэшированный SEO score
Миграция: python manage.py makemigrations Blog --name add_seo_fields

Файл: Blog/signals.py (создать новый)

Автогенерация meta_description из description или content (если не указан)
Автогенерация meta_keywords из тегов и контента
Автогенерация focus_keyword из title
Автоматический SEO анализ через SEOService
Файл: Blog/admin.py

Добавить SEO поля в админку с подсказками:

Показывать длину meta_title/description в реальном времени
