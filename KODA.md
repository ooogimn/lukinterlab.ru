# KODA: Контекст проекта LukInterLab

## Обзор проекта

Проект **LukInterLab** — это многофункциональная веб-платформа на Django, сочетающая в себе:

1. **Корпоративный сайт** с портфолио, отзывами, услугами и системой заказов
2. **Блог с автоматической генерацией контента** через GigaChat API
3. **AI-ассистента** для общения с посетителями
4. **Систему модерации** статей, комментариев и SEO-анализа
5. **Интеграцию с социальными сетями** (Telegram, VK, MAX) для автопостинга

### Основные технологии

- **Backend**: Django 5.0.8
- **База данных**: SQLite3 с кастомным бэкендом для WAL mode
- **Фоновые задачи**: Django-Q2
- **AI-интеграция**: GigaChat API (текст и изображения), OpenAI (опционально)
- **Фронтенд**: Bootstrap, JavaScript, CKEditor для редактирования контента
- **Админка**: Django Jazzmin
- **Кэширование**: локальное и файловое
- **Логирование**: ротируемые файлы логов

### Архитектура приложений

```
ALUKINTERLAB/          # Ядро проекта (настройки, middleware, кастомный DB backend)
├── home/              # Главное приложение: портфолио, отзывы, услуги, корзина, заказы
├── Blog/              # Блог: статьи, категории, комментарии, интеграция с соцсетями
├── Assistant/         # AI-ассистент: чат, генерация статей, промпты, расписания
├── Moderation/        # Модерация: статьи, комментарии, SEO-анализ
├── Users/             # Пользователи: кастомная аутентификация (Telegram)
└── templates/         # Шаблоны для всего проекта
```

## Установка и запуск

### 1. Настройка окружения

```bash
# Клонирование репозитория (если требуется)
# git clone <репозиторий>
# cd lukinterlab

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте файл `env.example` в `.env` в корне проекта и заполните необходимые значения:

```bash
cp env.example .env
```

**Ключевые переменные, которые необходимо заполнить:**

- `DJANGO_SECRET_KEY` — сгенерировать командой:
  ```bash
  python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
  ```
- `GIGACHAT_AUTHORIZATION_KEY` — ключ от GigaChat API (получить в личном кабинете Studio)
- `TELEGRAM_BOT_TOKEN` — токен бота для уведомлений и автопостинга
- `VK_ACCESS_TOKEN`, `VK_USER_ACCESS_TOKEN` — для интеграции с VK
- Данные для SMTP (если нужна отправка почты)

### 3. Инициализация базы данных

```bash
# Применение миграций
python manage.py migrate

# Создание суперпользователя (опционально)
python manage.py createsuperuser

# Сбор статических файлов
python manage.py collectstatic
```

### 4. Запуск сервера разработки

```bash
# Основной сервер Django
python manage.py runserver

# В отдельном терминале: воркер фоновых задач (обязательно для автогенерации статей)
python manage.py qcluster
```

### 5. Запуск на продакшене

Проект использует `passenger_wsgi.py` для совместимости с хостингами, поддерживающими Passenger (например, Timeweb). Настройки для продакшена:

- Установить `DJANGO_DEBUG=False` в `.env`
- Убедиться, что `ALLOWED_HOSTS` включает доменное имя
- Запустить воркер Django-Q как службу

## Основные функциональные модули

### Система автогенерации статей

**Расположение:** `Assistant/models.py`, `Assistant/services.py`

**Компоненты:**
- `PromptTemplate` — шаблоны промптов для заголовков, контента, изображений
- `AISchedule` — расписания автоматической генерации (ежечасная, ежедневная, CRON)
- `AIGeneratedArticle` — история генерации
- `ArticleGeneratorService` — основной сервис генерации

**Использование:**
1. Создать шаблон промпта в админке (AI-ассистент → Шаблоны промптов)
2. Настроить расписание генерации (AI-ассистент → Расписания генерации)
3. Запустить воркер: `python manage.py qcluster`

**Режимы генерации контента:**
- Генерация на основе промптов
- Парсинг новостей + дописывание
- Полный парсинг статей

### Блог и социальные сети

**Расположение:** `Blog/models.py`, `Blog/telegram_utils.py`, `Blog/vk_utils.py`, `Blog/max_utils.py`

**Функции:**
- Автоматическая публикация статей в Telegram-канал
- Постинг в VK (с превью изображений)
- Интеграция с мессенджером MAX
- Лайки, комментарии, SEO-поля

**Настройка интеграций:**
- Telegram: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID`
- VK: `VK_ACCESS_TOKEN`, `VK_USER_ACCESS_TOKEN`, `VK_GROUP_ID`
- MAX: `MAX_BOT_TOKEN`, `MAX_CHAT_ID`

### AI-ассистент

**Расположение:** `Assistant/models.py`, `Assistant/views.py`

**Возможности:**
- Чат-бот на основе GigaChat/OpenAI
- База знаний по услугам компании
- Персонализированные ответы
- Интеграция с Telegram для уведомлений администратора

**Настройки:** AI-ассистент → Настройки ассистента

### Система модерации

**Расположение:** `Moderation/models.py`, `Moderation/services.py`

**Модули:**
1. **Модерация статей** — автоматическая проверка по критериям
2. **Модерация комментариев** — фильтрация спама, автоответы
3. **SEO-анализ** — оценка статей по SEO-параметрам

**Критерии модерации:** настраиваются через JSON в админке.

### Портфолио и услуги

**Расположение:** `home/models.py`

**Сущности:**
- `Rabota` — работы в портфолио (сайты, боты, приложения)
- `Service` — основные услуги с ценами
- `Order` — система заказов
- `Cart` — корзина для онлайн-заказа услуг
- `SEOModel` — управление мета-тегами для страниц
- `LegalInfo` — правовая информация о компании

## Разработка

### Структура кода

Проект следует стандартной Django-архитектуре с некоторыми особенностями:

1. **PostgreSQL** — единственная поддерживаемая БД (настройки через `POSTGRES_*` в `.env`; см. `docs/JOURNAL_POSTGRES_REDIS.md`).
2. **Redis** — кэш Django и брокер Django-Q2 (`REDIS_URL`, `DJANGO_Q_REDIS_*`).
3. **Сигналы** для автоматических действий (публикация в соцсети при изменении статуса статьи)
4. **Сервисные классы** для сложной бизнес-логики
5. **Утилиты** для интеграций (Telegram, VK, MAX, GigaChat)

### Стиль кодирования

- **Именование:** snake_case для переменных и функций, CamelCase для классов
- **Документация:** комментарии на русском языке для бизнес-логики
- **Логирование:** использование модуля `logging` с конфигурацией в `settings.py`
- **Обработка ошибок:** try-except с записью в лог, пользователю — понятные сообщения

Логи сохраняются в папку `logs/`:

Модель `TokenUsage` отслеживает потребление токенов GigaChat API:

- Ежедневная статистика по моделям
- Расчет стоимости (если используется пакетная оплата)
- Лимиты токенов в зависимости от подписки

## Развертывание

### Требования к серверу

- Python 3.12+ (в Docker-образе — 3.13)
- PostgreSQL и Redis (см. `env.example`, `docs/JOURNAL_POSTGRES_REDIS.md`)
- Доступ к интернету для работы с API (GigaChat, Telegram, VK)

### Конфигурация веб-сервера

Пример для Passenger (Timeweb):

```apache
# .htaccess
PassengerAppRoot /home/username/path/to/project
PassengerPython /home/username/path/to/venv/bin/python
PassengerStartupFile passenger_wsgi.py
```

Альтернативно можно использовать **Gunicorn + Nginx**:

```bash
# Запуск Gunicorn
gunicorn ALUKINTERLAB.wsgi:application --bind 0.0.0.0:8000 --workers 3

# Запуск воркера Django-Q как службы
python manage.py qcluster
```

### Безопасность

1. **Секретные ключи** хранятся только в `.env` (не в репозитории)
2. **DEBUG режим** отключен на продакшене
3. **CSRF защита** настроена для домена
4. **Хеширование паролей** стандартное Django
5. **Шифрование чувствительных данных** в БД (API-ключи)

## Частые задачи

### Добавление новой социальной сети для автопостинга

1. Создать утилиту в `Blog/<network>_utils.py` с функцией `send_to_<network>_by_id(post_id)`
2. Добавить настройки в `settings.py` и `env.example`
3. Интегрировать в сигнал `publish_to_social` в `Blog/models.py`
4. Добавить поля времени публикации в модель `Post`

### Создание нового типа промпта

1. Добавить поле в модель `PromptTemplate`
2. Обновить `ArticleGeneratorService` для обработки нового типа промпта
3. Добавить логику в задачу генерации
4. Обновить админ-форму при необходимости

### Настройка новой категории блога

1. Создать категорию в админке (Блог → Категории)
2. Настроить `chat_id` для Telegram-канала (если нужен автопостинг)
3. Создать шаблон промпта, связанный с категорией
4. Настроить расписание генерации
